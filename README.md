# Math Game 🎮

A simple console-based math game developed using C++.

## Description

Math Game is a C++ console application that generates random mathematical questions and tests the user's ability to solve them.

The player can choose:
- Number of rounds
- Difficulty level (Easy, Medium, Hard, Mix)
- Operation type (Addition, Subtraction, Multiplication, Division, Mix)

At the end of the game, the program displays:
- Number of correct answers
- Number of wrong answers
- Final game result (Win, Lose, Draw)

## Features

- Random question generation
- Multiple difficulty levels
- Multiple mathematical operations
- Score tracking system
- Color feedback for correct and wrong answers
- Replay option

## Technologies Used

- C++
- Structures (`struct`)
- Enumerations (`enum`)
- Functions
- Random number generation
